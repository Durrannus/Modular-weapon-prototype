# Game prototype download (version 16, Windows)

Download: [game-prototype.zip](game-prototype.zip) (49 MB), then press "Download raw file".

1. Right-click the zip and choose "Extract All".
2. Double-click "Game prototype.exe".
3. If Windows says "Windows protected your PC", click "More info", then "Run anyway".

The read-me inside the zip lists the controls.
